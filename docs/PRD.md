# PRD: 모의 주식투자 게임 (Stock Simulator)

> 상태: **v1.0** — 질의응답 반영 완료 (구현 착수 대기)
> 작성일: 2026-10-16

---

## 1. 개요

### 1.1 한 줄 요약
가상의 한국 주식시장에서 가상 자금(원화)으로 주식을 사고팔며 수익률을 겨루는 **싱글 플레이 모바일 게임**.

### 1.2 배경 / 문제
- 주식 투자에 관심은 있지만 실제 돈을 잃을까 봐 시작하지 못하는 사람이 많다.
- 증권사 모의투자는 UI가 복잡하고 "게임"으로서의 재미(목표, 이벤트, 보상)가 부족하다.

### 1.3 목표
| 구분 | 목표 |
|---|---|
| 사용자 | 위험 없이 매수/매도·포트폴리오 관리를 체험한다 |
| 재미 | 뉴스 이벤트, 게임 모드, 업적으로 반복 플레이를 유도한다 |
| 학습 | 분산투자, 수수료·세금, 지정가, 배당 등 기본 개념을 자연스럽게 익힌다 |

### 1.4 프로젝트 성격
- **개인 / 포트폴리오 프로젝트.** 내 폰에서 Expo로 실행되면 충분하며 스토어 출시는 v1 범위 밖.

### 1.5 비목표 (v1)
- 실제 시세 연동, 실제 자금 거래, 증권사 계좌 연동
- 공매도, 신용/레버리지, 파생상품(옵션·선물)
- 회원가입·서버·온라인 랭킹 (→ v2 확장 고려, §9)
- 투자 자문/종목 추천

| 항목 | 결정 |
|---|---|
| 시세 데이터 | **가상 시장** — 알고리즘으로 시세 생성 (외부 API 없음) |

| 플레이 방식 | **싱글 플레이 먼저**, 로컬 저장. 온라인 기능은 추후 확장 |

| 세계관 | **한국식 · 원화(₩)**, 가상 한국 기업, 호가 단위·상하한가 ±30% |
| 종목 수 | **15~20개**, 5~6개 업종 |
| 게임 모드 | **기간제 / 목표 달성형 / 무한 모드** 중 선택 |

| 게임 요소 | **뉴스·시장 이벤트, 업적·뱃지, 튜토리얼·용어 설명, 난이도 선택** |
| 저장 | **자동저장 1슬롯 + 지난 게임 기록** |
| 디자인 | 한국식 색상(상승=빨강, 하락=파랑), 시스템 테마 따라 다크/라이트 |

| 캐주얼 게이머 | 투자보다 게임 자체를 즐김 | 짧은 세션, 배속, 이벤트·업적 |

## 4. 핵심 게임 루프

```
새 게임(모드·난이도 선택) → 시작 자금 지급
   → 종목 탐색 / 차트·뉴스 확인 → 매수(시장가·지정가)
   → 시간 경과(시세 변동, 뉴스 이벤트, 배당) → 매도·포트폴리오 조정
   → 종료 조건 도달 → 결과 정산(수익률·등급·업적) → 기록 저장 → 새 게임
```

## 5. 기능 요구사항

### 5.1 게임 설정

#### 난이도 (설정값은 코드에서 상수/설정 파일로 분리해 쉽게 조정)
| 난이도 | 시작 자금 | 시장 변동성 | 악재 이벤트 빈도 |
|---|---|---|---|
| 쉬움 | 3,000만 원 | 낮음 | 낮음 |
| 보통 | 1,000만 원 | 보통 | 보통 |
| 어려움 | 300만 원 | 높음 | 높음 |

#### 게임 모드
| 모드 | 규칙 |
|---|---|
| 기간제 | 게임 내 3개월 / 6개월 / 1년(250거래일, 1x 기준 약 4시간) 중 선택. 종료 시 최종 수익률로 등급(S~F) 정산 |
| 목표 달성형 | 총자산 **2배** 달성 시 클리어, **50% 이하**로 떨어지면 게임오버 |
| 무한 모드 | 종료 조건 없음, 언제든 수동 종료/리셋 |

### 5.2 시간 / 시장 엔진
- 1거래일 = 실제 60초 (1x 기준), 배속 1x / 2x / 4x, 일시정지.
- 앱이 백그라운드로 가거나 종료되면 **시간도 정지** (재접속 시 이어서 진행).
- 1거래일 내에서 일정 간격(예: 1초)으로 가격 틱 생성 → 장중 차트 표현.
- 주말·공휴일 개념 없음 (거래일만 진행).
- **가격 모델:** 종목별 기대수익률·변동성 기반의 랜덤워크(기하 브라운 운동) + 시장 전체 요인 + 업종 요인 + 뉴스 이벤트 충격.
- **한국식 규칙:**
  - 호가 단위(가격대별 1/5/10/50/100/500/1,000원) 적용
  - 전일 종가 대비 **±30% 상하한가**
- 재현성을 위해 게임마다 시드(seed) 기반 난수 사용.

### 5.3 종목
- 15~20개 가상 한국 기업, 5~6개 업종 (예: IT·반도체, 바이오, 금융, 에너지, 소비재, 엔터)
- 종목 속성: 이름, 업종, 시작가, 변동성, 기대 성장률, 배당 여부·배당률, 설명 문구
- 업종 지수 및 전체 시장 지수(예: "가상 종합지수") 제공

### 5.4 주문 / 체결
- **시장가 매수·매도:** 현재가로 즉시 체결.
- **지정가 매수·매도:** 지정 가격 도달 시 체결. 미체결 주문 목록에서 취소 가능. 미체결 주문은 해당 거래일 장 마감 시 자동 취소
- **매수 시 현금 묶임:** 지정가 매수 주문 금액(+수수료)은 주문 시점에 예약.
- **수수료:** 매수·매도 각 0.015% (설정값)
- **세금:** 매도 금액의 0.18% (설정값)
- **검증:** 잔고 부족, 보유 수량 초과 매도, 상하한가 범위 밖 지정가, 호가 단위 불일치 차단.
- 단위: 1주 단위, 소수점 거래 없음.

### 5.5 배당
- 배당 종목은 분기(게임 내 약 62거래일)마다 배당 지급
- 배당 기준일에 보유한 수량 × 주당 배당금을 현금으로 지급, 배당락 반영.
- 배당 지급 시 알림 + 거래 내역 기록.

### 5.6 뉴스 / 시장 이벤트
- 종목·업종·시장 단위 가상 뉴스 발생 (호재/악재/중립)
- 뉴스는 해당 대상의 가격에 충격(단발 + 수일간 추세)을 준다.
- 대형 이벤트: 폭락장, 버블, 금리 인상 등 시장 전체 이벤트 (낮은 확률)
- 뉴스 피드 화면 + 중요 뉴스는 인게임 배너 알림
- 난이도에 따라 악재 빈도·충격 크기 조정

### 5.7 포트폴리오 / 자산
- 보유 현금, 주식 평가금액, 총자산, 총 수익률(원금 대비)
- 보유 종목별: 수량, 평균 매입가, 현재가, 평가손익, 수익률, 비중
- 자산 구성 파이 차트, 총자산 추이 라인 차트
- 거래 내역(체결·배당·수수료·세금)

### 5.8 업적 / 뱃지
- 예시: 첫 매수, 첫 수익 실현, 수익률 +10/+50/+100%, 5개 업종 분산, 상한가 종목 보유, 폭락장에서 생존, 배당금 누적 100만 원, 각 모드 클리어
- 업적은 게임 간 누적(영구) 저장, 업적 목록 화면 제공

### 5.9 튜토리얼 / 용어 설명
- 첫 실행 시 단계별 튜토리얼(종목 보기 → 매수 → 시간 진행 → 매도) — 건너뛰기 가능
- 주요 용어(시장가, 지정가, 평균단가, 상한가, 배당, 수수료 등)에 ⓘ 툴팁
- 용어 사전 화면

### 5.10 저장 / 기록
- 진행 중인 게임 1개를 기기에 **자동저장**(거래·하루 경과 시점)
- 게임 종료 시 기록 보관: 모드, 난이도, 기간, 최종 수익률, 등급, 최고 보유 종목, 날짜
- 기록 화면: 지난 게임 목록, 모드별 최고 기록
- 설정: 진행 중 게임 포기, 전체 데이터 초기화

## 7. 비기능 요구사항
- **성능:** 4x 배속에서도 60fps에 가까운 부드러운 UI, 시세 갱신 지연 체감 없음
- **오프라인:** 네트워크 없이 완전 동작
- **데이터 보존:** 앱 재시작 후에도 진행 상태·기록·업적 유지
- **언어:** 한국어
- **테마:** 시스템 설정에 따라 다크/라이트, 상승=빨강 / 하락=파랑
- **테스트:** 시세 엔진·주문 체결·수수료/세금/배당 계산은 단위 테스트로 검증 (시드 고정)

## 8. 기술 스택 (제안)
- React Native + **Expo** (TypeScript), Expo Router
- 상태 관리: Zustand
- 로컬 저장: AsyncStorage (필요 시 expo-sqlite)
- 차트: react-native-wagmi-charts 또는 victory-native (구현 시 검토)
- 테스트: Jest
- 게임 로직(시세 엔진·주문·정산)은 UI와 분리된 순수 TypeScript 모듈로 작성

## 10. 남은 미결정 사항
- 차트 라이브러리 선택 (구현 단계에서 결정)
